# StFX Research Experts Directory – Mockups

Design mockups for a searchable research-experts directory, in StFX colours. All names, photos and details are placeholder sample data.

Open `index.html` to compare all options.

| File | Option |
|---|---|
| `option-f-classic.html` | **F – Reference layout.** Matches the reference page's layout. A single self-contained file: the list and every profile page are in it. |
| `option-a-showcase.html` | A – Showcase: hero search, theme tiles, sidebar filters, rich profile |
| `option-b-table.html` | B – Simple table |
| `option-d-quickview.html` | D – Option F-style list (one per row, large photo) with a quick-view side panel |
| `option-d-editable.html` | D + editing (demo) – staff sign-in, dashboard and per-professor edit form. Demo edits are saved in the visitor’s own browser only. Single self-contained file. |
| `profile.html` | Shared profile page used by options B and D |

`shared.js` / `shared.css` hold the sample data and styles used by options B and D. Option F has its own copy of the data inside the file.

## Hosting on GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)`. Note that free GitHub Pages requires the repository to be public.
